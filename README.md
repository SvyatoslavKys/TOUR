# TOUR

An adaptive camping-tour landing page rebuilt with React and Vite. The project
keeps the original visual direction and photography while completing the
navigation, tour details, reviews and booking flow.

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

The GitHub Actions workflow builds `dist/` and deploys it to GitHub Pages after
changes reach `main`.
